# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

delegated: Streamlit multipage app with Plotly and Folium, because the competition team needs an explainable Python-first dashboard that can run locally and deploy publicly.

## Users

生鲜食品客户、企业调度人员和业务沟通人员。客户需要快速了解配送范围、预计到达和费用；企业人员需要确认车辆安排并复核订单结果。

## Product Purpose

将客户订单整理为易读的配送方案，直接呈现配送范围、车辆安排、路线、预计到达和费用。成功标准是客户可以看懂结果，企业人员可以据此沟通和安排执行。

## Positioning

面向生鲜配送业务的轻量计划工具。它保留真实路线和结果依据，但优先展示业务人员真正需要的信息，而不是完整展示算法过程。

## Operating Context

网站主要面向客户沟通、企业日常配送安排和本地离线复核；竞赛展示也可直接使用。公网版本通过 Streamlit Community Cloud 访问，本地版本使用 Python 启动。

## Capabilities and Constraints

- 读取网站数据目录中的轻量 JSON、CSV 和 GeoJSON。
- 支持上传 Excel、CSV 和已保存的结果 JSON，生成车辆、路线、预计到达和费用。
- 展示配送总览、订单概览、配送地图、车辆安排、费用与服务、方案比较。
- 不在公网运行完整 ALNS，不上传大型 GPKG、GraphML 或 OSM 文件。
- 仅使用当前最终结果，较优可行解不描述为全局最优。
- 缺失数据显示暂无可验证数据，不自动编造或强制补零。

## Evidence on Hand

网站数据由竞赛目录中的鲜面条、姜蒜专线、第二问车辆复用和载重续航最终结果文件整理生成。原始成果包不由网站改写。

## Product Principles

- 结论先行，指标可追溯。
- 路线、时间窗和成本必须在同一条讲解链路上。
- 真实数据优先于演示效果。
- 上传后先给出快速可行草案，正式结果可以直接读取已保存文件。

## Accessibility & Inclusion

保持单一浅色主题、高对比文字、明确单位、键盘可操作控件和减少动效支持，适配企业日常查看、客户沟通与窄屏设备。
