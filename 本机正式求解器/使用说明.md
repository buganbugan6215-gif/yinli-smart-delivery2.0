# 本机 Dijkstra 路网精算器

该程序运行在保存了货车路网 GPKG 的企业电脑上，不在 Streamlit Cloud 中运行。

## 使用步骤

1. 在企业工作台下载 `Dijkstra任务.zip` 并解压。
2. 安装一次依赖：`pip install -r requirements-local.txt`。
3. 执行：

```powershell
python 路网Dijkstra订单求解.py --orders orders.xlsx --road-gpkg "D:\A-university\竞赛\第六届四川省物流设计大赛\7.0-修复孤立客户拓扑节点.gpkg" --output result
```

4. 将 `result/formal_result.json` 上传到企业工作台。
5. 网站校验结果确为 Dijkstra 路网路径后，才会开放“确认配送方案”和“车辆发出”。

## 输出

- `formal_result.json`：网页回传文件，含单订单正式路线 GeoJSON。
- `distance_matrix.xlsx`：配送中心与订单点的最短距离矩阵。
- `route_map.geojson`：可在 GIS 软件中打开的路网路线。

## 口径

订单点和配送中心将吸附到既有货车路网节点；Dijkstra 在有向道路图上使用 `length_m` 作为权重。当前脚本计算路网最短路，车辆多客户排序仍需要在下一步接入已改造成动态输入的 MATLAB VRPTW 求解器。
