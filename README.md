# 银犁智慧配送平台

基于 Streamlit 的客户下单、订单追踪和工作人员统一调度平台。网站以当前订单为依据计算配送方案；车辆地图位置为演示仿真，不是车载 GPS 实时定位。

## 客户端

| 页面 | 当前功能 |
|---|---|
| 客户下单 | 填写地址、联系电话、品类、重量及收货时间窗；提交前查看预估费用。鲜面条和姜蒜可一次提交，生成按品类拆分、分别配送的子单。 |
| 订单追踪 | 使用订单号和联系电话后四位查询状态、路线及预计到达时间；未发车的订单可申请取消。预计时间按计划发车、道路里程、分段车速、前序站点等待及服务时间逐站计算。 |
| 我的配送地图 | 查看本订单的路线与站点，按道路距离和车速演示车辆行驶及站点停留；可调演示倍率，悬停查看站点等待与服务时间。地图提供较大范围路网，细支道路按需加载。 |
| 确认签收 | 到货后确认签收或提交异常反馈。 |

北京时间每日 20:00 截止次日订单：19:59:59 及以前提交，最早选择次日；20:00 起最早选择后天。客户也可预约更晚的配送日期。工作人员提前确认完整配送批次后，该配送日停止接单。

## 工作人员：六个入口

| 入口 | 当前功能 |
|---|---|
| 订单台账 | 按配送日或近 30 天历史查询实际订单，查看联系电话、订单状态和异常反馈，导出筛选结果。 |
| 统一调度 | 按选定日期读取完整批次，切换单仓／双仓，结合订单时间窗灵活安排发车；计算、确认线路，演示发车，登记送达并导出方案。 |
| 配送地图 | 查看所选仓库、当前计算方案，以及已确认的配送和补货线路。 |
| 运营分析 | 汇总实际订单与计划成本，比较同批订单的单仓／双仓方案。 |
| 车辆与计价 | 维护车辆数量、载重、续航、成本、行驶速度和客户报价参数。 |
| 订单数据管理 | 备份、迁移和清理订单；清理操作需输入确认文字。 |

鲜面条和姜蒜分别用车，求解及确认时均检查不能混装。线路基于仓库随项目提供的道路网络和当前订单计算；计划成本与预计时间属于模型估算，不代表实际结算或实时车载数据。无订单或无已确认方案时，业务页面展示空态。

## 本地运行

~~~powershell
pip install -r requirements.txt
streamlit run app.py
~~~

工作人员密码通过 YL_STAFF_PASSWORD 环境变量或 Streamlit secrets 设置。订单默认保存在本地 SQLite；YL_ORDER_DATA_DIR 可指定数据目录，YL_DATABASE_URL 可配置外部 PostgreSQL，配置方法见[云端订单保存配置](云端订单保存配置.md)。订单数据库、密码和 secrets 不纳入 Git。部署在无持久化磁盘的环境时，应配置外部数据库并先备份现有订单。

网站运行所需的路网位于 路网数据/，地图展示文件为 网站数据_页面读取的指标/road_major.geojson 和 road_minor.geojson。路网来源与生成方式见[路网数据说明](路网数据/README.md)。单仓／双仓方案说明见[双仓接入说明](双仓接入说明.md)。
