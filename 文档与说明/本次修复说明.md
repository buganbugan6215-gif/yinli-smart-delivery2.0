# 客户配送闭环与部署修复说明

## 已修复

1. 下单即生成订单专属演示路线，客户地图不再长期停留在空状态。
2. 演示订单会在约 20 秒内依次推进至“配送途中”；“配送完成”只能通过客户签收产生。
3. 电子签收严格校验状态，未进入“配送途中”时按钮不可用。
4. 时间窗默认值调整为 08:00—18:00。
5. 新增“工作人员配送全图”，与客户单订单地图分离。
6. 侧边栏默认展开，并恢复 Streamlit 默认导航作为备用入口。
7. 工作人员密码改由 `STAFF_PASSWORD` 环境变量或 Streamlit Secret 提供。
8. 订单改存数据库：本地默认 SQLite，公网可通过 `DATABASE_URL` 连接 PostgreSQL。
9. 客户只看到当前会话订单；更换浏览器后需用“订单编号 + 下单联系电话”恢复，不会列出他人订单。
10. 订单编号包含完整日期、毫秒和随机后缀，避免同秒碰撞。
11. 地址识别改为点击后请求并缓存；网络失败时使用明确标注的成都区级/市级演示定位。
12. 地图可关闭在线底图，仅显示项目内置路网，离线能力说明已按真实情况修改。
13. 页面编号统一为 01—04（客户）和 10—17（工作人员），无重复前缀。
14. 预估费用改为“起步服务费 + 品类重量服务费 + 参考里程费”，页面显示拆解。
15. 分散的“未接入/待接入”提示收敛为统一的演示数据范围说明。

## 部署前必须配置

在 Streamlit Community Cloud 的 Secrets 中至少设置：

```toml
STAFF_PASSWORD = "你的工作人员密码"
```

需要在云端重启后保留订单时，再设置：

```toml
DATABASE_URL = "postgresql://用户名:密码@主机:5432/数据库名"
```

不要把真实密码或数据库连接串提交到公开 GitHub 仓库。

## 演示建议

1. 客户下单并查看透明费用拆解。
2. 进入订单追踪，打开专属地图确认路线已经生成。
3. 约 20 秒后刷新进度，订单进入“配送途中”。
4. 进入电子签收并确认收货，状态变为“配送完成”。
5. 打开新的浏览器会话，使用订单号和联系电话恢复订单，演示隐私隔离与持久化能力。
